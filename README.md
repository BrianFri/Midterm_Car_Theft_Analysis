# U.S. Car Theft Analysis Dashboard

An interactive Streamlit web application that explores vehicle theft patterns across all U.S. states. The dashboard provides visualizations and insights into total thefts, theft rates per capita, and the most/least stolen vehicle models both nationally and by state.

## Project Overview

This dashboard was built to analyze and communicate patterns in vehicle theft data. It allows users to explore:

- Which states have the highest total vehicle thefts
- Theft rates adjusted for population (per 100,000 residents)
- The most and least commonly stolen vehicle models
- State-specific insights through an interactive deep-dive feature

## Features

- **State Theft Totals**: Bar chart and table showing total reported thefts by state
- **Theft Rate per 100k**: Choropleth map and table showing population-adjusted theft rates
- **Most Stolen Vehicles**: National rankings by model and model + year
- **Most/Least Stolen by State**: Interactive maps showing the top stolen model in each state
- **State Deep Dive**: Select any state from the sidebar to see its specific theft data and metrics
- **Interactive Controls**: Slider to adjust number of states shown and dropdown for state selection
